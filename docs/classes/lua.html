Class lua

Lua table conversion helpers.

These functions are registered on the JSON module. parse_table is an alias for parse_lua; element instances expose :totable() and :tolua().

JSON:parse_lua (t[, as[, mixed_name[, no_mixed]]])
Convert a Lua table to a LuaJson element.

Parameters:

  • t table Table to convert.
  • as string "-a" for array, "-o" for object, "-p" for parse mode, or an option containing "v" for verbose output. (optional)
  • mixed_name string Field name used when preserving mixed-key data. (optional)
  • no_mixed boolean When true, ignore mixed-key fixups. (optional)

Returns:

    array|object Converted JSON element.

Usage:

    local t = {1, 2, 3.45, "test", true}
local a = JSON:parse_lua(t, "-a")
print(a:tojson()) --> [1,2,3.45,"test",true]

JSON:stringify_lua (value[, mode[, escape]])
Serialize a Lua table or LuaJson element.

Parameters:

  • value table|array|object Value to serialize.
  • mode string "json" for JSON output or "lua" for Lua table output. (optional)
  • escape boolean Escape quotes in the rendered string. (optional)

Returns:

    string Serialized value.

Usage:

    local t = {1, 2, 3, 4, 5}
 print(JSON:stringify_lua(t, "json")) --> [1,2,3,4,5]
