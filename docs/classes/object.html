Class object

Ordered JSON object.

Objects preserve insertion order and allow key-based or position-based access. Numeric indexes address ordered key/value pairs; string indexes address named fields.

object:tojson ([start[, finish[, escape]]])
Render the object as JSON.

Parameters:

  • start string|number Start key or ordered index. (optional)
  • finish string|number End key or ordered index. (optional)
  • escape boolean Escape quotes in the returned string. (optional)

Returns:

    string JSON object text.

Usage:

    local obj = JSON:object("name", "test", "value", 42, "root", null)
print(obj:tojson())              --> {"name":"test","value":42,"root":null}
print(obj:tojson("name", "value")) --> {"name":"test","value":42}
