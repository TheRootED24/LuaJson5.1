Module JSON

LuaJson module.

The module exposes callable array and object factory tables plus helpers for parsing JSON strings, converting Lua tables, and rendering JSON elements.

Arrays are zero-indexed by default. Call json_base(1) on an element to use Lua-style one-based indexing for numeric API calls.

print(a:tojson()) --> [1,2,3.45,true]

parse_lua (t[, as[, mixed_name[, no_mixed]]])
Convert a Lua table into a LuaJson element.

Parameters:

  • t table Table to convert.
  • as string Conversion option: "-a" for array, "-o" for object, "-p" to parse and return the converted element, or include "v" for verbose output. (optional)
  • mixed_name string Field name used for mixed table members. (optional)
  • no_mixed boolean When true, ignore mixed-key fixups. (optional)

Returns:

    array|object Converted JSON element.

Usage:

    local t = {1, 2, 3.45, "test", true}
local a = JSON:parse_lua(t, "-a")
print(a:tojson()) --> [1,2,3.45,"test",true]
