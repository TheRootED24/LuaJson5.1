Introduction

A High-Performance, Memory-Safe JSON Serializer for Lua 5.1, 5.3, and 5.4

LuaJson provides native array and object container types for Lua with high-performance JSON serialization, mutable JavaScript-style APIs, and memory-safe rendering paths.

Unlike standard Lua tables, LuaJson containers preserve insertion order, support positional mutation operations, and expose a dedicated serialization API.

LuaJson objects and arrays support:

  • Ordered mutation operations
  • Fast JSON rendering
  • Lua table serialization
  • Reference-aware copy semantics
  • Circular reference protection
  • Cross-VM compatibility
  • Memory-safe rendering paths

Steady-State DOM Construction Benchmark

On embedded ARM:

  • ~0.56 ms (light run)
  • ~0.98 ms (heavy/steady run)
  • ~50–300 MB/s effective throughput range depending on measurement method

Full CRUD API

Specialized array and object classes with methods such as:

  • push / pop
  • shift / unshift
  • reverse / move
  • ref / unref
